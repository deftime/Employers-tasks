### Задача:

Зробити картку продавця (аддон) згідно наданого макету, яка відображається на кожній сторінці товару, на сайті ecommerce-рушія CS-Cart, стандартної теми Responsive.

Картка отримує певні дані, які передаються з адмінки у шаблон.

Картка має показувати спливаюче вікно по кліку у двох режимах - модалка або попап. Режим визначається налаштуванням картки в адмінці, дані вибраного режиму передаються в картку.

Базові стартові налаштування нового аддону вже були зроблені і надані, фокус завдання на фронтовій частині, а також дослідженню самого рушія CS-Cart.

### Особливість:

## vendor_showcase — starter add-on

Базовый аддон для тестового задания Frontend-разработчику на **CS-Cart Multi-Vendor 4.18.1+**.

Цель каркаса — убрать из тестового задания необходимость разбираться с backend CS-Cart. После установки аддон регистрирует новый тип блока **«Карточка продавца»**, получает продавца текущего товара и передаёт подготовленные данные в Smarty.

## Что уже сделано

- зарегистрирован собственный тип блока `vendor_showcase` через `schemas/block_manager/blocks.post.php`;
- добавлен шаблон блока `vendor_card.tpl`;
- в настройках блока есть `Вид панели`: `popup` / `modal`;
- серверная функция определяет продавца по `product_id` текущей страницы;
- в `$vendor_card` передаются:
  - `company_id`;
  - `name`;
  - `url`;
  - `logo` (`src`, `width`, `height`) или `null`;
  - `initials`;
  - `description` — plain text, до 300 символов;
- если страница не является страницей товара или у товара нет продавца, `$vendor_card` пустой и шаблон ничего не выводит.

## Что специально НЕ сделано

Это стартовый каркас. Кандидат должен реализовать frontend-часть задания:

- итоговую вёрстку карточки;
- компонентную структуру;
- popup;
- modal;
- LESS/CSS;
- JavaScript и поведение после AJAX-перерисовки;
- доступность;
- адаптив.

В `vendor_card.tpl` оставлена только простая диагностическая разметка, чтобы сразу было видно, что блок установлен, продавец найден, а настройка `popup/modal` передаётся.

## Установка

Архив содержит структуру каталогов относительно корня CS-Cart:

```text
app/
var/
README.md
```

1. Распаковать содержимое архива в корень чистой установки CS-Cart Multi-Vendor.
2. В админке открыть **Модули → Управление модулями** и установить/включить `Карточка продавца` (`vendor_showcase`).
3. Открыть **Дизайн → Макеты** и перейти в локацию страницы товара.
4. Добавить новый блок типа/шаблона **Карточка продавца**.
5. В настройках блока выбрать **Вид панели → Попап** или **Модальное окно**.
6. Открыть на витрине товар, принадлежащий продавцу.

> На страницах, где `product_id` отсутствует, блок намеренно не выводит содержимое.

## Что получает шаблон

```smarty
{$vendor_card.company_id}
{$vendor_card.name}
{$vendor_card.url}
{$vendor_card.logo}
{$vendor_card.initials}
{$vendor_card.description}

{$block.properties.panel_mode} {* popup | modal *}
```

Предполагаемая точка входа frontend-решения:

```smarty
{if $vendor_card}
    {$panel_mode = $block.properties.panel_mode|default:"popup"}

    {* Кандидат передаёт $vendor_card и $panel_mode в свои компоненты. *}
{/if}
```

## Структура

```text
app/addons/vendor_showcase/
├── addon.xml
├── func.php
└── schemas/
    └── block_manager/
        └── blocks.post.php

var/themes_repository/responsive/templates/addons/vendor_showcase/
└── blocks/
    └── vendor_card.tpl

var/langs/en/addons/vendor_showcase.po
var/langs/ru/addons/vendor_showcase.po
```

После установки CS-Cart копирует файлы темы из `var/themes_repository` в рабочую тему в `design/themes`.

## Debug для разработки

В корне магазина можно создать/изменить `local_conf.php`:

```php
<?php

define('DEVELOPMENT', true);
define('DEBUG_MODE', true);

error_reporting(E_ALL);
ini_set('display_errors', 'on');
ini_set('display_startup_errors', true);

$config['tweaks']['disable_block_cache'] = true;
```

Если новый шаблон/схема не подхватываются:

1. очистить кэш CS-Cart; для 4.18.1 удобно открыть `admin.php?cc&ctpl`;
2. деактивировать и снова активировать аддон;
3. если менялись `var/themes_repository`, `addon.xml` или `.po`, переустановить/refresh аддон, чтобы файлы снова попали в рабочие каталоги.

## Важное замечание

Каркас статически проверен (PHP syntax, XML, структура архива), но в этой среде нет установленного экземпляра CS-Cart Multi-Vendor 4.18.1, поэтому полноценный runtime-тест установки и Block Manager не выполнялся. Перед выдачей кандидату стоит один раз установить архив на чистую 4.18.1 и проверить создание блока в `Дизайн → Макеты`.
