**Реалізовано на чистому HTML/SJ + SCSS через звичайний NPM-проєкт.  
Ніякого ШІ для генерації коду. (Але спілкування для пошуку оптимальних ідей реалізації фішки До/Після).  

Застосовано власну систему надтонких відносних одиниць, які приймають значення пікселів відносно розміру макета та розраховують точні значення VW.**  

Стартова точка розрахунку 1:1 Макет Десктоп - **1200**  
Мобільна точка розрахунку 1:1 Макет Мобайл - **375**  
Точка мобайлу - **500**  
Адаптація інтерфейсу для великих екранів - **безкінечна**

Загальний час мінімальної реалізованої частини - **7 годин**.  
За 2 години такий макет НЕ робиться, а враховуючи низьку якість макету - тим паче.

### Особливості деяких елементів:

- Для кнопки у першому слайді використано платний ліцензіцний шрифт **Gilroy**. Не можна використовувати шрифти на сторінках без веб-ліцензії. Замінено на Inter.
- Для ефекту паралакс перший блок на макеті **НЕ ГОТОВИЙ**. Ефект не робиться з нічого, для реалізації необіхдно в першу чергу готувати макет із всіма необхідними елементами та структурою. А перший блок у нас це просто набір шматків із фейковим перекритим фоном. Там нічого паралаксити.
- Для бігунка До/Після у другому блоці макет **НЕ ГОТОВИЙ**. Тем не менш він зроблений через танці з бубном у режимі Редагування. На макеті мають бути чітко доступні для експорту дві картинки точно однакових розмірів. А не шматочки, які висмикнуті із великих зображень-джерел.

> **Єдині складнощі, з якми я стикнувся під час роботи - це жахливий макет.**

_Ймовірно це результат теж тестового завдання, але для дизайнерів. Або сильне зловживання ШІ._

- Що це за стартовий розмір Десктопу в 1200? Немає таких екранів, це або великий планшет, або дуже малий ноутбук. Якщо зменшуємо до середнього - це 1440, а бажано брати сучасний 1920.
- Фейкові приховані фони, над якими наліплені шматки інших зображень. Ну це треш. Коли я був лідом фронтів, за таке я бив дизайнерів по руках і вони в мене все перероблювали.
- Іде некоректний експорт елементів, вони обрізаються, беруть невірний розмір, їх важко знайти в структурі.
- Недостатньо даних для публічного закритого макету, доводиться копіювати та розбирати його у себе у режимі Редагування, граючись в дизайнера.
- Елементи зроблені у спосіб, який не дозволяє їх експортувати як ассет. Наприклад, другий слайд, текст у зеленому блоці, білі графічні накладки.
- Збиті зони текстів, що не дозволяє визначати точні відстані
- Перший слайд - це просто набір шматочків які перемішані і накладені один на одний як мозайка.

Немає цілістності, структурності, схеми, доступності ассетів, розробник вимушений розбирати і збирати самостійно всі елементи через копію у режимі Редагування. Це значно збільшує час роботи і не дозволяє повноцінно реалізувати усе задумане на дизайні.
